# E0604: deriving Eq also requires PartialEq

## Why
`Eq` is the total-equality refinement of `PartialEq`. Every `Eq`
type must also be `PartialEq`, because `==` is defined on
`PartialEq`. Deriving `Eq` alone would produce a type that claims
total equality without supplying the underlying comparison.

## Example
```rvn
@[derive(Eq)]
struct Id
  value: Int
end
```

## Fix
Derive both:

```rvn
@[derive(PartialEq, Eq)]
struct Id
  value: Int
end
```
