# E0617: auto-synth Ord: field type does not satisfy Ord

## Why
Auto-synthesized `Ord` provides a lexicographic `cmp` over the
fields in declaration order. Every field type must therefore
satisfy `Ord`. Floats are not `Ord` because NaN breaks totality;
user types satisfy `Ord` only when their own fields do.

## Example
```rvn
struct Sample
  rank: Int
  score: Float              # not Ord (NaN)
end

def main
  let a = Sample.new(1, 0.5)
  let b = Sample.new(2, 0.6)
  if a < b                  # error[E0617]: Float is not Ord
    puts "lower"
  end
end
```

## Fix
Replace the non-`Ord` field with one that is `Ord`, or order on a
quantised representation:

```rvn
struct Sample
  rank: Int
  score_bits: Int64        # ordered totally
end
```
