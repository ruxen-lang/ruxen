# E0617: derive Ord: field type does not implement Ord

## Why
`derive Ord` synthesizes a lexicographic `cmp` over the fields in
declaration order. Every field type must therefore implement `Ord`.
Floats are not `Ord` because NaN breaks totality; user types must
themselves derive or implement `Ord`.

## Example
```rvn
@[derive(PartialEq, Eq, PartialOrd, Ord)]
struct Sample
  rank: Int
  score: Float
end
```

## Fix
Replace the non-`Ord` field with one that is `Ord`, or order on a
quantised representation:

```rvn
@[derive(PartialEq, Eq, PartialOrd, Ord)]
struct Sample
  rank: Int
  score_bits: I64
end
```
