# E1703 — empty regex pattern

A `/pat/flags` regex literal had no body between the opening and
closing `/`.

## Example (rejected)

```ruxen
let r = //   # E1703: empty regex pattern
```

## Why

An empty pattern is ambiguous to read and almost never the author's
intent — a literal `//` looks like a line comment in many languages,
and an empty PCRE2 pattern matches every position (zero-width) which
is rarely useful. Reject it at lex time to keep the surface
unambiguous.

## Fix

Either supply a pattern:

```ruxen
let r = /./       # matches any single character
let r = /.*?/     # zero-width "match anywhere"
```

…or use the runtime constructor if you genuinely want an empty
pattern at runtime:

```ruxen
let r = Regex.new("", "").unwrap!
```
