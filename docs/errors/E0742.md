# E0742: no overload of the function takes this argument type

## Why

A free function is defined more than once with different parameter types
(overloads), and the argument at this position fits none of them. An
argument may be a borrow of the parameter type or coerce to it (an `Int`
literal to a `Float`), but nothing else.

## Example

```rx
def show(x: Int) -> Int
  x
end

def show(x: Bool) -> Bool
  x
end

def main
  show(2.5)
  # error[E0742]: no overload of `show` takes a `Float` argument
end
```

## Fix

Pass a value one overload takes, or add an overload for the type.

```rx
def show(x: Float) -> Float
  x
end
```
