# E0606: deriving Ord also requires Eq and PartialOrd

## Why
`Ord` is the total-ordering refinement built on top of `Eq` and
`PartialOrd`. Synthesizing `cmp` is meaningful only when the
related equality and partial-order traits are also in scope. The
compiler asks for them explicitly so the trait stack is consistent.

## Example
```rvn
@[derive(Ord)]
struct Version
  major: Int
  minor: Int
end
```

## Fix
List the full set:

```rvn
@[derive(PartialEq, Eq, PartialOrd, Ord)]
struct Version
  major: Int
  minor: Int
end
```
