# E1128: value cannot be indexed

## Why
`x[i]` works on an `Array`, a `Hash`, a `String` (one character), a fixed-size
array with a literal index, and any class that defines `def []`. Any other
receiver has no index operation.

The compiler used to accept these and produce an unset value at runtime. It is
now an error.

## Example
```rx
def main
  let t = (1, 2)
  let i = 1
  puts t[i]        # error[E1128]: a tuple cannot be indexed
end
```

## Fix
- Destructure a tuple instead: `let (a, b) = t`.
- Index a fixed-size array with an integer literal (`a[0]`), or use an
  `Array` for a computed index.
- Define `def [](i: Int)` on your class to make it indexable.
