# E1128: value cannot be indexed

## Why
`x[i]` works on an `Array`, a `Hash`, a `String` (one character), a fixed-size
array with a literal index, and any class that defines `def []`. Scalars
(`Int`, `Float`, `Bool`) and tuples have no index operation, so indexing one is
E1128. (A class without `def []` reports E0740, no such method.)

The compiler used to accept these and produce an unset value at runtime. It is
now an error.

## Example

Rejected with E1128 [implemented]:

```ruby
f = 2.5
i = 0
puts f[i]        # error[E1128]: a Float cannot be indexed
```

## Fix
- Use an `Array` for a computed index (tuples are [deprecated]; arrays replace
  them), or index a fixed-size array with an integer literal (`a[0]`).
- Define `def [](i: Int)` on your class to make it indexable.

Compiles and prints `2` [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Point
  x: Int
  y: Int

  def init(x: Int, y: Int)
    @x = x
    @y = y
  end

  def [](i: Int) -> Int
    if i == 0
      @x
    else
      @y
    end
  end
end

pt = Point.new(1, 2)
i = 1
puts pt[i]
```
