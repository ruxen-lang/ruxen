# E0714: method called on a module instead of a class inside it

## Why
A `module` is a namespace. It holds classes, but it is not a value and has
no methods of its own, so `Module.method(...)` has nothing to call.

The standard library's buffered I/O is the common case: `BufReader` and
`BufWriter` are modules, each holding one class per inner stream
(`BufReader.File`, `BufReader.Tcp`, `BufWriter.File`, `BufWriter.Tcp`).

## Example
```rx
# error[E0714]: `BufReader` is a module, not a class, so it has no method `new`
let f = File.open("data.txt").unwrap
let br = BufReader.new(f)
```

## Fix
Call the method on the class inside the module that fits the value:
```rx
let f = File.open("data.txt").unwrap
var br = BufReader.File.new(f)
let line = br.read_line
```

For a TCP stream use `BufReader.Tcp.new(stream)`; `with_capacity(cap, inner)`
lives on the same classes.

## Notes
- The message lists every class declared directly inside the module.
