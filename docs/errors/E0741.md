# E0741: argument type does not match the class method's parameter

## Why

An argument passed to a class method of a builtin type (`Array`, `Set`,
`Hash`, `String`, ...) does not fit the type the method declares for that
parameter. An argument may be a borrow of the parameter type or coerce to it
(a smaller integer to a wider one), but nothing else.

## Example

```rx
def main
  let xs: Array[Int] = Array.with_capacity("8")
  # error[E0741]: argument `cap` of `with_capacity` expects `Int`, found `String`
end
```

## Fix

Pass a value of the declared type.

```rx
def main
  let xs: Array[Int] = Array.with_capacity(8)
  puts xs.size
end
```
