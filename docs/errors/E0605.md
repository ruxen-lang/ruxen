# E0605: cannot synthesize Default on enum without a `default` variant

## Why
Unlike a struct (where `Default` is the field-wise default), an
enum has no canonical zero variant. Auto-synthesis of `Default`
on an enum needs the author to mark exactly one variant with the
`default` directive so the synthesized `Default.default` knows
which arm to construct.

## Example
```rx
enum Mode
  Read
  Write
  Append
end

def main
  let m: Mode = Mode.default    # error[E0605]: no default variant
end
```

## Fix
Mark the chosen variant:

```rx
enum Mode
  default Read
  Write
  Append
end
```
