# E0605: cannot derive Default on enum without a `@[default]` variant

## Why
Unlike a struct (where `Default` is the field-wise default), an
enum has no canonical zero variant. The `derive(Default)` machinery
needs the author to mark exactly one variant with `@[default]` so
the synthesized `Default::default()` knows which arm to construct.

## Example
```rvn
@[derive(Default)]
enum Mode
  Read
  Write
  Append
end
```

## Fix
Annotate the chosen variant:

```rvn
@[derive(Default)]
enum Mode
  @[default] Read
  Write
  Append
end
```
