# E0006: unexpected character

## Why
The lexer encountered a byte that is not part of any token in the
Ruxen grammar — typically a stray symbol, a smart-quote pasted from
a word processor, or a non-ASCII character outside an identifier or
string literal.

## Example
```rx
def main
  let x = 1 § 2
  puts "#{x}"
end
```

## Fix
Replace the stray character with a real operator (or remove it):

```rx
def main
  let x = 1 + 2
  puts "#{x}"
end
```
