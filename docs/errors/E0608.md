# E0608: unknown mixin requested for auto-synthesis

## Why
Auto-synthesis (§3.6) covers a fixed set of built-in mixins:
`Debug`, `Clone`, `Copy`, `PartialEq`, `Eq`, `Hashable`, `Default`,
`Ord`, `PartialOrd`. A type's body cannot request synthesis for
anything outside this list. User-defined mixins must be supplied
by an explicit `include` directive with method bodies.

The diagnostic stays registered for the (rare) internal call
that asks the synthesizer to operate on an unrecognised mixin
name.

## Example
```rx
mixin Serializable
  def to_json -> String
end

struct Config
  name: String

  include Serializable          # error[E0608]: not a synthesizable mixin
end
```

## Fix
Provide the mixin's required methods directly in the type body:

```rx
struct Config
  name: String

  include Serializable

  def to_json -> String
    "{\"name\":\"#{self.name}\"}"
  end
end
```
