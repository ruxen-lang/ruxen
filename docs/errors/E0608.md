# E0608: unknown derive trait

## Why
The name inside a `@[derive(...)]` attribute is not one of the
built-in derivable traits (`Debug`, `Clone`, `Copy`, `PartialEq`,
`Eq`, `Hash`, `Default`, `Ord`, `PartialOrd`). Custom derive macros
are not yet supported in v1, so unrecognised names are an error
rather than a forwarded macro call.

## Example
```rvn
@[derive(Serialize)]
struct Config
  name: String
end
```

## Fix
Remove the unsupported trait or write a manual `impl`:

```rvn
@[derive(Debug, Clone)]
struct Config
  name: String
end
```
