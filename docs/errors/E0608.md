# E0608: unknown mixin requested for auto-synthesis

## Why
An `include` inside a type body names a mixin. When the name is one of
the structural mixins the compiler synthesizes (`Clone`, `Copy`, and
the [deprecated] Rust-named ones: `Debug`, `PartialEq`, `Eq`,
`Hashable`, `Default`, `Ord`, `PartialOrd`), the compiler writes the
methods. Any other name must resolve to a declared mixin or type.

E0608 fires when the name is neither: usually a typo, or a mixin that
was never declared or required.

## Example

Rejected with E0608 [implemented]:

```ruby
class Config
  name: String
  include Clnoe      # typo: no mixin or type has this name
end
```

## Fix
Spell the mixin correctly, or declare (or `require`) the mixin you
meant.

Compiles [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Config
  name: String

  def init(name: String)
    @name = name
  end
  include Clone
end

a = Config.new("prod")
puts a.clone.name
```
