# E1002: cannot borrow as mutable — already borrowed as immutable

## Why
Riven enforces "either many readers or one writer". An immutable
borrow (`&x`) is already live in the current region, so the
compiler refuses to grant a mutable borrow (`&mut x`) that would
let one alias write while the others read.

## Example
```rvn
def main
  var v: Array[Int] = Array.new
  v.push(1)
  let r = &v          # immutable borrow live below
  v.push(2)           # E1002: needs &mut v while &v is live
  puts "#{r.len}"
end
```

## Fix
Let the immutable borrow end (drop it, or limit its scope) before
taking the mutable borrow:

```rvn
def main
  var v: Array[Int] = Array.new
  v.push(1)
  do
    let r = &v
    puts "#{r.len}"
  end
  v.push(2)
end
```
