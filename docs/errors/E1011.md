# E1011: type does not satisfy Send

## Why
A value crossing a thread boundary (e.g. into `spawn`'s closure)
must implement `Send`. The compiler found a field or capture whose
type is `!Send` — typically a `Rc`, a non-thread-safe handle, or a
borrow that would race across threads.

## Example
```rvn
def main
  let r = Rc.new(1)
  spawn move ||
    puts "#{r}"   # E1011: Rc<Int> is not Send
  end
end
```

## Fix
Replace the non-Send capture with a Send-safe equivalent (for
shared ownership across threads, use `Arc` instead of `Rc`):

```rvn
def main
  let r = Arc.new(1)
  spawn move ||
    puts "#{r}"
  end
end
```
