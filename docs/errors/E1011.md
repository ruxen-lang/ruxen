# E1011: type does not satisfy Send

## Why
A value crossing a thread boundary (e.g. into `spawn`'s closure)
must satisfy `Send`. The compiler found a field or capture whose
type is `!Send` — typically a `Shared`, a non-thread-safe handle,
or a borrow that would race across threads.

## Example
```rx
def main
  let r = Shared.new(1)
  spawn move ||
    puts "#{r}"   # E1011: Shared[Int] is not Send
  end
end
```

## Fix
Replace the non-Send capture with a Send-safe equivalent. For
shared ownership across threads, use `SharedSync` instead of
`Shared`:

```rx
def main
  let r = SharedSync.new(1)
  spawn move ||
    puts "#{r}"
  end
end
```
