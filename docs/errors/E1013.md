# E1013: non-`static` value captured by send-required closure

## Why
A closure handed to `spawn` must outlive any thread that runs it,
which the compiler models as a `static` lifetime bound. The
closure captured a borrow whose lifetime ends when the spawning
function returns — the spawned thread could outlive that storage.

## Example
```rx
def run
  let s = String.from("hi")
  spawn ||
    puts s          # E1013: borrow of s does not satisfy `static`
  end
end
```

## Fix
Move the value into the closure (`move ||`), or relocate the
storage into a `static` / `SharedSync` so the lifetime is long
enough:

```rx
def run
  let s = String.from("hi")
  spawn move ||
    puts s
  end
end
```
