# E0732: nil-coalescing operator requires Option and a matching fallback

## Why

The `??` operator unwraps an `Option[T]` or evaluates a fallback value when the
Option is `nil`. Its left operand must therefore be `Option[T]`, and its right
operand must produce `T`.

```rx
let value = 1 ?? 2
# error[E0732]: `??` requires an Option on the left
```

## Fix

Use an Option on the left and a fallback with the contained type.

```rx
let configured: Option[Int] = nil
let value = configured ?? 2
```

The fallback is lazy. It is evaluated only when the left operand is `nil`.
Chained fallbacks associate to the right, so `a ?? b ?? value` works when both
`a` and `b` are `Option[T]`.
