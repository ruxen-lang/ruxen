# E0609: duplicate include of an auto-synthesized mixin

## Why
A type can include each structural mixin (`Clone`, `Copy`, and the
[deprecated] Rust-named ones: `Debug`, `PartialEq`, `Eq`, `Hashable`,
`Default`, `Ord`, `PartialOrd`) at most once. Repeating an `include`
for one of these names is almost always a copy-paste mistake and would
otherwise silently shadow the first synthesis.

## Example

Rejected with E0609 [implemented]:

```ruby
class Point
  x: Int
  y: Int
  include Clone
  include Clone        # duplicate include of Clone
end
```

## Fix
Drop the duplicate.

Compiles [implemented]:

```ruby
class Point
  x: Int
  y: Int
  include Clone
end
```
