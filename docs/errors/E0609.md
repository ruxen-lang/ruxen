# E0609: duplicate derive trait

## Why
The same trait was named twice in a single `@[derive(...)]` list (or
across multiple `@[derive(...)]` attributes on the same item). Each
trait can only be synthesized once; a duplicate is almost always a
copy-paste mistake and would otherwise silently shadow the first
definition.

## Example
```rvn
@[derive(Clone, Debug, Clone)]
struct Point
  x: Int
  y: Int
end
```

## Fix
Drop the duplicate:

```rvn
@[derive(Clone, Debug)]
struct Point
  x: Int
  y: Int
end
```
