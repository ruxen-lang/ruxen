# E0609: duplicate include of an auto-synthesized mixin

## Why
A type can include each auto-synthesized mixin (`Debug`, `Clone`,
`Copy`, `PartialEq`, `Eq`, `Hashable`, `Default`, `Ord`, `PartialOrd`)
at most once — and in practice does not need to include them at
all, because synthesis is automatic when the fields qualify
(§3.6). Repeating an `include` for one of these names is almost
always a copy-paste mistake and would otherwise silently shadow
the first synthesis.

## Example
```rx
struct Point
  x: Int
  y: Int

  include Clone
  include Debug
  include Clone        # error[E0609]: duplicate include of Clone
end
```

## Fix
Drop the duplicate — and, for auto-synthesizable mixins, drop the
explicit `include` entirely. The compiler synthesizes them when
every field qualifies:

```rx
struct Point
  x: Int
  y: Int               # Debug, Clone, Copy auto-synthesized
end
```
