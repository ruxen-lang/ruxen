# E0603: Copy cannot be auto-synthesized on a class; use a struct

## Why
Ruxen `class`es have reference identity and (potentially) destructors.
`Copy` would silently alias that identity and skip drop, which is
almost never what the author wants. The compiler reserves auto-
synthesized `Copy` for plain-old-data `struct`s.

The diagnostic fires when a user tries to force a `class` into
`Copy`-shaped use (e.g., assigning across bindings without `clone`
on a type that would otherwise be eligible).

## Example
```rx
class Counter
  value: Int
end

def main
  let a = Counter.new(0)
  let b = a              # error[E0603]: class Counter is not Copy
  a.value = a.value + 1
  puts "#{b.value}"
end
```

## Fix
Either convert the type to a `struct` (if it really is plain data
with no identity), or use explicit `clone`:

```rx
struct Counter
  value: Int             # struct: all-Copy fields → Copy synthesized
end
```

```rx
class Counter
  value: Int

  def clone -> Counter
    Counter.new(self.value)
  end
end

def main
  let a = Counter.new(0)
  let b = a.clone        # explicit duplicate
end
```
