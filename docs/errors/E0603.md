# E0603: Copy cannot be derived on a class; use a struct

## Why
Riven `class`es have reference identity and (potentially) destructors.
`Copy` would silently alias that identity and skip drop, which is
almost never what the author wants. The compiler reserves `Copy` for
plain-old-data `struct`s.

## Example
```rvn
@[derive(Copy, Clone)]
class Counter
  value: Int
end
```

## Fix
Either convert the type to a `struct` (if it really is plain data),
or drop `Copy` and rely on explicit `Clone`:

```rvn
@[derive(Clone)]
class Counter
  value: Int
end
```
