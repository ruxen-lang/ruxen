# E1004: cannot move out of borrowed reference

## Why
A reference (`&T` or `&mut T`) lends access to a value but does not
own it. Moving the pointee out would leave the underlying storage
in an invalid half-initialised state for the original owner.

## Example
```rvn
def take(s: &String) -> String
  let inner = *s   # E1004: cannot move out of &String
  inner
end
```

## Fix
Clone the value, or change the signature to take ownership:

```rvn
def take_clone(s: &String) -> String
  s.clone()
end

def take_owned(s: String) -> String
  s
end
```
