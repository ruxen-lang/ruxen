# E0737: `where` predicate does not constrain a generic parameter

## Why

A `where` predicate attaches a mixin bound to a generic parameter. The
left-hand side must be a type parameter of the function or of its
enclosing class, struct or enum. Bounds on associated types (`T.Item`),
on concrete types (`Int`) or on unknown names are not supported, and used
to be ignored without a word.

## Example

```rx
def total[T](items: &Array[T]) -> Int where Int: Add
  0
end
# error[E0737]: `where` predicate must constrain a generic parameter of this
# function or its enclosing type; ...
```

## Fix

Put the bound on a generic parameter.

```rx
mixin Named
  def name -> String
end

def greet[T](pet: &T) -> String where T: Named
  "hello " + pet.name
end
```
