# E0001: unterminated block comment

## Why
The lexer reached end-of-file while still inside a `=begin` / `=end`
block comment (or a `/* ... */` C-style block comment). Block comments
must be closed before the source ends; otherwise the compiler cannot
tell where comment text stops and code begins.

## Example
```rx
=begin
this comment never closes and EOF arrives first
def main
  puts "hello"
end
```

## Fix
Add the matching `=end` (or `*/`) terminator on its own line:

```rx
=begin
this is a properly closed comment
=end
def main
  puts "hello"
end
```
