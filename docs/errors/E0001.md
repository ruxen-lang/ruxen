# E0001: unterminated block comment

## Why
The lexer reached end-of-file while still inside a `#= ... =#` block
comment. Block comments nest, so every `#=` needs its own `=#`, and all
of them must be closed before the source ends; otherwise the compiler
cannot tell where comment text stops and code begins.

Ruby's `=begin` / `=end` block comment is
[planned](../../TODO.md#t-begin-comment); until it lands, `#= ... =#` is
the block comment form.

## Example

Rejected with E0001 [implemented]:

```ruby
#= this comment never closes and EOF arrives first
puts "hello"
```

## Fix
Add the matching `=#` terminator (one per opening `#=`).

Compiles [implemented]:

```ruby
#= this is a properly closed comment =#
puts "hello"
```
