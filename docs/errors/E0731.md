# E0731: logical operator requires Bool operands

## Why

Ruxen does not use Ruby-style truthiness. The logical operators `&&`, `||`,
`and`, `or`, and keyword `not` accept only `Bool` operands.

```rx
let value = 1 and 2
# error[E0731]: logical operator `and` requires Bool operands
```

## Fix

Write a comparison or predicate that produces a `Bool`.

```rx
let value = count > 0 and ready
let missing = not found
```

Both symbolic and keyword binary operators short-circuit, so the right operand
is evaluated only when the left operand does not determine the result.
