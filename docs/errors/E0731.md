# E0731: logical operator requires Bool operands

## Why

Ruxen does not use Ruby-style truthiness yet. The logical operators `&&`,
`||`, `and`, `or`, and keyword `not` accept only `Bool` operands. Ruby
truthiness (`user || default` on a `T?`, `x ||= 1` on an `Int`) is
[planned](../../TODO.md#t-truthiness).

## Example

Rejected with E0731 [implemented]:

```ruby
value = 1 and 2
# error[E0731]: logical operator `and` requires Bool operands
```

## Fix

Write a comparison or predicate that produces a `Bool`.

Compiles [implemented]:

```ruby
count = 3
ready = true
found = false
value = count > 0 and ready
missing = not found
puts value
puts missing
```

Both symbolic and keyword binary operators short-circuit, so the right operand
is evaluated only when the left operand does not determine the result.
