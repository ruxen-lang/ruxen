# E0008: `None` is not valid; use `nil`

## Why
Ruxen has a single empty literal, `nil`. It stands for `Option::None`,
a null pointer and unit. The identifier `None` is rejected wherever it
appears (expression, pattern or type position) so there is one way to
write the empty value.

## Example
```rx
def main
  let x: Int? = None
  puts x
end
```

## Fix
Write `nil` instead:

```rx
def main
  let x: Int? = nil
  puts x
end
```
