# E0004: invalid numeric literal

## Why
The lexer started reading a numeric literal but the digits, base
prefix, suffix, or exponent were malformed — for example an empty
hex literal (`0x`), repeated underscores, a hex digit in a decimal
literal, or an exponent without digits.

## Example
```rx
def main
  let bad = 0x
  puts "#{bad}"
end
```

## Fix
Provide the digits the prefix promises, or drop the prefix:

```rx
def main
  let ok = 0xFF
  puts "#{ok}"
end
```
