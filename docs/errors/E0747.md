# E0747: a compiler-supplied parameter is not last

## Why

A `lib` declaration can ask the compiler for a descriptor of a type with a
parameter of type `ElemDesc[T]` (how a `T` is copied and freed) or
`KeyDesc[K]` (the same, plus how a `K` hashes and compares as a table key).
Callers never pass these parameters: the compiler appends them at every
call. They must therefore come after every parameter a caller writes, or the
arguments a caller passes would land in the wrong positions.

## Example

```rx
class Box[T]
  lib "box.c"
    # error[E0747]: `Box_lead` declares a compiler-supplied parameter
    # before a parameter its callers pass
    def lead as "box_lead"(elems: ElemDesc[T], n: Int) -> Int
  end
end
```

## Fix

Move the compiler-supplied parameters to the end:

```rx
    def lead as "box_lead"(n: Int, elems: ElemDesc[T]) -> Int
```
