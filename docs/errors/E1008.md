# E1008: value moved into closure, cannot be used outside

## Why
A `move` closure (or a closure that the borrow checker upgraded to
move because of how it captures a non-`Copy` value) takes ownership
of its captures. After construction, the original binding is no
longer usable — the closure holds it.

## Example
```rx
def main
  let s = String.from("hi")
  let c = move || puts s
  puts s          # E1008: s moved into closure c
  c.()
end
```

## Fix
Use the value before the move, clone it for the closure, or borrow
instead of move:

```rx
def main
  let s = String.from("hi")
  let c = || puts s.clone
  puts s
  c.()
end
```
