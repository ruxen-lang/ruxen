# E0611: auto-synth Clone: unsupported field shape (e.g. opaque foreign type)

## Why
Auto-synthesized `Clone` walks the structure of a type and emits a
per-field clone call. Some shapes have no structure the
synthesizer can walk — notably opaque foreign types declared in
`lib` blocks, unions, and FFI handles. On those shapes the user
must supply a `clone` method by hand inside the type body.

## Example
```rx
lib "ffi"
  type FFIHandle
end

struct Wrapper
  handle: FFIHandle           # opaque to the synthesizer
end

def main
  let a = Wrapper.new(/*...*/)
  let b = a.clone             # error[E0611]: cannot walk FFIHandle
end
```

## Fix
Either replace the field with a Ruxen type the synthesizer can
walk, or provide a manual `clone` in the type body:

```rx
struct Wrapper
  handle: Int

  def clone -> Wrapper
    Wrapper.new(self.handle)
  end
end
```
