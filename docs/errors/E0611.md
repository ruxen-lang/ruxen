# E0611: derive Clone: unsupported shape (e.g. extern type)

## Why
`derive Clone` walks the structure of a type and emits a per-field
clone call. Some shapes have no structure the synthesizer can walk —
notably `extern type`s (opaque to Riven), unions, and FFI handles.
On those shapes the user must write the `Clone` impl by hand.

## Example
```rvn
extern type FFIHandle

@[derive(Clone)]
struct Wrapper
  handle: FFIHandle
end
```

## Fix
Either drop the derive and supply a manual `impl Clone`, or change
the field to a Riven type the synthesizer can walk:

```rvn
struct Wrapper
  handle: Int
end

impl Clone for Wrapper
  fn clone(self) -> Wrapper
    Wrapper { handle: self.handle }
  end
end
```
