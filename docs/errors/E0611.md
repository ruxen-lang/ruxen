# E0611: auto-synth Clone: unsupported field shape (e.g. opaque foreign type)

## Why
This code is registered but not emitted today. It was reserved for a
synthesized `Clone` that meets a field shape it cannot walk, such as
an opaque foreign handle.

Today that case reports **E0610**: a field whose type is an opaque C
handle (for example `Mutex[Int]`) does not satisfy `Clone`, and the
type that says `include Clone` is rejected there.

## Example

A field the synthesizer cannot copy, rejected with E0610 [implemented]:

```ruby
class Wrapper
  handle: Mutex[Int]     # opaque C handle
  include Clone
end
```

## Fix
Replace the field with a type the synthesizer can walk, or drop
`include Clone` and write the `clone` method by hand.

Compiles [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Wrapper
  handle: Int

  def init(handle: Int)
    @handle = handle
  end

  def clone -> Wrapper
    Wrapper.new(@handle)
  end
end

a = Wrapper.new(7)
puts a.clone.handle
```
