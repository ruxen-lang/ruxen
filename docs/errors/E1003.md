# E1003: cannot borrow as immutable — already borrowed as mutable

## Why
A mutable borrow (`&var x`) is exclusive: while it is live, no
other borrow — mutable or immutable — may exist. The compiler
refused to issue an immutable read because that would alias an
in-flight write.

## Example
```rvn
def main
  var v: Array[Int] = Array.new
  let m = &var v
  let r = &v          # E1003: immutable borrow while &var v is live
  m.push(1)
  puts "#{r.len}"
end
```

## Fix
Sequence the borrows so they don't overlap:

```rvn
def main
  var v: Array[Int] = Array.new
  do
    let m = &var v
    m.push(1)
  end
  let r = &v
  puts "#{r.len}"
end
```
