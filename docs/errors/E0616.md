# E0616: auto-synth Default: enum's first variant has fields without Default

## Why
For enums whose fields qualify for auto-synthesized `Default`, the
synthesizer constructs the `default` variant (or the first variant
if none is marked). If that variant has payload fields, every
payload field must itself satisfy `Default` — otherwise the
synthesized `Default.default` would have no value to put there.

## Example
```rx
lib "ffi"
  type RawHandle
end

enum Resource
  default Open(handle: RawHandle)    # RawHandle is not Default
  Closed
end

def main
  let r: Resource = Resource.default  # error[E0616]
end
```

## Fix
Either pick a no-payload variant as the default, or replace the
payload type with one that satisfies `Default`:

```rx
enum Resource
  default Closed
  Open(handle: Int)
end
```
