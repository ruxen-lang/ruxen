# E0616: derive Default: enum's first variant has fields without Default

## Why
For enums marked with `derive(Default)`, the synthesizer constructs
the `@[default]` variant (or the first variant). If that variant has
payload fields, every payload field must itself be `Default` —
otherwise the synthesized `Default::default()` would have no value
to put there.

## Example
```rvn
extern type RawHandle

@[derive(Default)]
enum Resource
  @[default] Open(handle: RawHandle)
  Closed
end
```

## Fix
Either pick a no-payload variant as the default, or replace the
payload type with one that implements `Default`:

```rvn
@[derive(Default)]
enum Resource
  @[default] Closed
  Open(handle: Int)
end
```
