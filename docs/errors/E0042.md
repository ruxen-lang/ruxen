# E0042: diagnostic-fixture sentinel (tests only)

## Why
This code is reserved for the diagnostics test-suite and is never
emitted by the real compiler. It exists so unit tests in
the compiler's diagnostics module can exercise the `code` field of a
`Diagnostic` without colliding with codes that map to user-visible
errors.

## Example
E0042 is not produced by user code. The compiler's own diagnostics
tests construct a diagnostic with this code directly.

## Fix
You should never see this code from a real compile. If you do, it
indicates a test fixture leaked into a release build — please file
an issue on the Ruxen repository.
