# E0613: auto-synth PartialEq: field type does not satisfy PartialEq

## Why
Auto-synthesized `PartialEq` provides an `==` that compares fields
pair-wise. Every field must therefore itself satisfy `PartialEq`,
otherwise there would be no way to compare it.

## Example
```rx
lib "ffi"
  type RawHandle
end

struct Pair
  a: Int
  b: RawHandle              # not PartialEq
end

def main
  let p = Pair.new(/*...*/)
  let q = Pair.new(/*...*/)
  if p == q                 # error[E0613]: RawHandle is not PartialEq
    puts "equal"
  end
end
```

## Fix
Either remove the offending field, replace it with a type that
satisfies `PartialEq`, or write the `==` method manually inside
the type body:

```rx
struct Pair
  a: Int
  b: Int                    # primitives satisfy PartialEq
end
```
