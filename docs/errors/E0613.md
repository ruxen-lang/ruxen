# E0613: derive PartialEq: field type does not implement PartialEq

## Why
`derive PartialEq` synthesizes an `==` that compares fields
pair-wise. Every field must therefore itself implement
`PartialEq` — otherwise there would be no way to compare it.

## Example
```rvn
extern type RawHandle

@[derive(PartialEq)]
struct Pair
  a: Int
  b: RawHandle
end
```

## Fix
Either remove the offending field, replace it with a type that
implements `PartialEq`, or write the `PartialEq` impl manually:

```rvn
@[derive(PartialEq)]
struct Pair
  a: Int
  b: Int
end
```
