# E0618: derive PartialOrd: field type does not implement PartialOrd

## Why
`derive PartialOrd` synthesizes a lexicographic `partial_cmp` over
the fields in declaration order. Each field type must implement
`PartialOrd`. User types satisfy this by deriving it themselves;
opaque or extern types do not.

## Example
```rvn
extern type RawHandle

@[derive(PartialEq, PartialOrd)]
struct Pair
  a: Int
  b: RawHandle
end
```

## Fix
Either replace the offending field, or derive `PartialOrd` on the
inner type:

```rvn
@[derive(PartialEq, PartialOrd)]
struct Pair
  a: Int
  b: Int
end
```
