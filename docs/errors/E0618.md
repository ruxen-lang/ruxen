# E0618: auto-synth PartialOrd: field type does not satisfy PartialOrd

## Why
Auto-synthesized `PartialOrd` provides a lexicographic
`partial_cmp` over the fields in declaration order. Each field
type must satisfy `PartialOrd`. User types satisfy this when their
own fields do; opaque foreign types do not.

## Example
```rx
lib "ffi"
  type RawHandle
end

struct Pair
  a: Int
  b: RawHandle              # not PartialOrd
end

def main
  let p = Pair.new(/*...*/)
  let q = Pair.new(/*...*/)
  if p < q                  # error[E0618]
    puts "lower"
  end
end
```

## Fix
Either replace the offending field, or arrange for the inner type
to satisfy `PartialOrd`:

```rx
struct Pair
  a: Int
  b: Int                    # primitives satisfy PartialOrd
end
```
