# E1014: invalid `unsafe impl` declaration

## Why
`unsafe impl` is reserved for asserting marker traits (`Send`,
`Sync`) on types whose safety the compiler cannot verify. The
compiler rejected this declaration because either the trait is
not an unsafe marker, or the body is not empty, or the type is not
eligible (for example, an `unsafe impl` for a non-marker trait).

## Example
```rvn
unsafe impl Clone for Handle
  fn clone(self) -> Handle
    self
  end
end
```

## Fix
Drop `unsafe` for non-marker traits and write a normal `impl`, or
limit `unsafe impl` to the empty marker form:

```rvn
impl Clone for Handle
  fn clone(self) -> Handle
    self
  end
end

unsafe impl Send for Handle
end
```
