# E1014: invalid `unsafe include` declaration

## Why
`unsafe include` is reserved for asserting marker mixins (`Send`,
`Sync`) on types whose safety the compiler cannot verify. The
compiler rejected this declaration because either the mixin is not
an unsafe marker, or the include carries method bodies (markers
have none), or the type is not eligible (for example, an
`unsafe include` of a non-marker mixin).

## Example
```rvn
class Handle
  unsafe include Clone        # error[E1014]: Clone is not an unsafe marker

  def clone -> Handle
    self
  end
end
```

## Fix
Drop `unsafe` for non-marker mixins and use a plain `include`, or
limit `unsafe include` to the empty marker form:

```rvn
class Handle
  include Clone

  def clone -> Handle
    self
  end
end

class Handle2
  unsafe include Send
end
```
