# E0615: auto-synth Hashable: field type is not hashable

## Why
Auto-synthesized `Hashable` provides a `hash` method that feeds each
field into the hasher. Every field type must therefore satisfy
`Hashable`. Floating-point types and types containing `Float32` /
`Float64` are not hashable in Ruxen (their NaN behaviour breaks
the hash–equality contract).

## Example
```rx
struct Sample
  id: Int
  value: Float           # not Hashable
end

def main
  var seen: Set[Sample] = Set.new
  seen.insert(Sample.new(1, 0.5))   # error[E0615] at use site
end
```

## Fix
Drop the non-hashable field, replace it with an integer-quantised
form, or write `hash` manually with a documented quantisation
strategy:

```rx
struct Sample
  id: Int
  value_bits: UInt64     # quantised: satisfies Hashable
end
```
