# E0615: derive Hash: field type is not hashable

## Why
`derive Hash` synthesizes a `hash` method that feeds each field
into the hasher. Every field type must therefore implement `Hash`.
Floating-point types and types containing `f32`/`f64` are not
hashable in Riven (their NaN behaviour breaks the hash–equality
contract).

## Example
```rvn
@[derive(Hash)]
struct Sample
  id: Int
  value: Float
end
```

## Fix
Drop the non-hashable field, replace it with an integer-quantised
form, or implement `Hash` manually with a documented quantisation
strategy:

```rvn
@[derive(Hash)]
struct Sample
  id: Int
  value_bits: U64
end
```
