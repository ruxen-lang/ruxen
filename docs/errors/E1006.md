# E1006: cannot assign to immutable variable

## Why
Most bindings can be reassigned, as in Ruby: a local introduced by
`x = 1` and a method parameter are both mutable. A few bindings are
fixed for their whole scope: the variable of a `for` loop (it is
rebound on each pass), the parameters of a block or lambda, and a local
introduced with the [deprecated] `let` keyword (replaced by plain
`x = 1`). Assigning to one of these is rejected.

## Example

Rejected with E1006 [implemented]:

```ruby
for i in 0..3
  i = i * 2        # E1006: the loop variable is fixed
  puts i
end
```

## Fix
Copy the value into a local of your own and change that.

Compiles and prints `0`, `2`, `4`, `6` [implemented]:

```ruby
for i in 0..3
  doubled = i
  doubled = doubled * 2
  puts doubled
end
```
