# E1006: cannot assign to immutable variable

## Why
Bindings introduced with `let` are immutable. The compiler rejected
an attempt to reassign such a binding because the author did not
declare the binding mutable with `var`.

## Example
```rx
def main
  let count = 0
  count = count + 1   # E1006: count is immutable
  puts "#{count}"
end
```

## Fix
Use `var` for mutable bindings, or shadow the binding with a new
`let`:

```rx
def main
  var count = 0
  count = count + 1
  puts "#{count}"
end
```
