# E1006: cannot assign to immutable variable

## Why
Bindings introduced with `let` are immutable by default. The
compiler rejected an attempt to reassign such a binding because
the author did not opt into mutability with `let mut`.

## Example
```rvn
def main
  let count = 0
  count = count + 1   # E1006: count is immutable
  puts "#{count}"
end
```

## Fix
Add `mut`, or shadow the binding with a new `let`:

```rvn
def main
  let mut count = 0
  count = count + 1
  puts "#{count}"
end
```
