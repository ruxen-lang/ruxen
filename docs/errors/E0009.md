# E0009: `..=` is not valid range syntax; use `..`

## Why
Ruxen ranges follow Ruby: `a..b` includes `b` and `a...b` excludes it.
The Rust inclusive form `a..=b` is not part of the language. The lexer
rejects it and recovers as `..`.

## Example
```rx
def main
  for i in 1..=3
    puts i
  end
end
```

## Fix
Use `..` for an inclusive range (or `...` to exclude the end):

```rx
def main
  for i in 1..3
    puts i
  end
end
```
