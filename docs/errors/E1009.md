# E1009: cannot move value — currently borrowed

## Why
A live borrow is pointing at the value, so moving it elsewhere
would leave the borrow dangling. The borrow checker insists every
borrow end before its referent can be relocated.

## Example
```rvn
def main
  let mut v = Vec.new()
  v.push(1)
  let r = &v
  let w = v       # E1009: v is borrowed by r
  puts "#{r.len()} #{w.len()}"
end
```

## Fix
End the borrow before the move:

```rvn
def main
  let mut v = Vec.new()
  v.push(1)
  do
    let r = &v
    puts "#{r.len()}"
  end
  let w = v
  puts "#{w.len()}"
end
```
