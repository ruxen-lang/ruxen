# E0735: undefined function

## Why

A call names a function that is not defined in this file, in a file it
`require`s, or in the standard library prelude.

## Example

Rejected with E0735 [implemented]:

```ruby
greet("Ada")
# error[E0735]: undefined function `greet`
```

## Fix

Define the function, fix the spelling, or `require` the file that provides it.

Compiles [implemented]:

```ruby
def greet(name: &String)
  puts("Hello, #{name}")
end

greet("Ada")
```

In the REPL a definition that calls a function defined later is
accepted and compiled once the callee arrives.
