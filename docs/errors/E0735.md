# E0735: undefined function

## Why

A call names a function that is not defined in this file, in a `use`d
module, or in the standard library prelude.

## Example

```rx
def main
  greet("Ada")
  # error[E0735]: undefined function `greet`
end
```

## Fix

Define the function, fix the spelling, or `use` the module that provides it.

```rx
def greet(name: &String)
  puts("Hello, #{name}")
end
```

In the REPL a definition that calls a function defined later is
accepted and compiled once the callee arrives.
