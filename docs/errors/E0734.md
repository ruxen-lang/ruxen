# E0734: undefined variable

## Why

A bare name was used as a value, but no local, parameter, constant or
function with that name is in scope.

## Example

Rejected with E0734 [implemented]:

```ruby
puts(totl)
# error[E0734]: undefined variable `totl`
```

## Fix

Fix the spelling, or bind the name before using it.

Compiles [implemented]:

```ruby
total = 3
puts(total)
```

## A field name without `@`

Inside a method a bare name is a local variable or a method call, never a
field (Ruby's rule). Read a field as `@name`. When the class, or one of its
ancestor classes, declares a field with the bare name, the error says so.

Rejected with E0734 [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Pt
  x: Int

  def init(@x: Int)
  end

  def double -> Int
    x * 2
    # error[E0734]: undefined variable `x`
    #   = help: `x` is a field of `Pt`; read it as `@x`. A bare name is a
    #     local variable or a method call.
  end
end
```

Compiles [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Pt
  x: Int

  def init(@x: Int)
  end

  def double -> Int
    @x * 2
  end
end

puts Pt.new(4).double
```

A class method (`def self.make`) has no instance, so there is no `@x` to
read; the help says to read the field from an instance, such as `pt.x`.
A bare assignment such as `x = 1` declares a new local and leaves `@x`
unchanged, as in Ruby. A bare call to a method of `self` is
[planned](../../TODO.md#t-implicit-self).
