# E0734: undefined variable

## Why

A bare name was used as a value, but no local, parameter, constant or
function with that name is in scope.

## Example

```rx
def main
  puts(totl)
  # error[E0734]: undefined variable `totl`
end
```

## Fix

Fix the spelling, or bind the name before using it.

```rx
def main
  total = 3
  puts(total)
end
```
