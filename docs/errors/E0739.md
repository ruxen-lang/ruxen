# E0739: `main` cannot take parameters

## Why

The program entry point is called by the operating system with the fixed
C `main(argc, argv)` signature. Ruxen passes those arguments to `std.env`
before your `main` body runs, so a free `def main` takes no parameters of
its own. A parameter list used to reach code generation and crash the
compiler.

## Example

```rx
def main(name: String)
  puts "hello #{name}"
end
# error[E0739]: `main` cannot take parameters; read program arguments with `Env.args`
```

## Fix

Read the program arguments with `Env.args`.

```rx
def main
  args = Env.args
  puts "hello #{args.len}"
end
```
