# E0003: invalid escape sequence

## Why
A backslash inside a string or character literal was followed by a
character the lexer does not recognise as a valid escape. Ruxen
supports the usual `\n`, `\r`, `\t`, `\\`, `\"`, `\'`, `\0`, plus
hex (`\xNN`) and unicode (`\u{NNNN}`) forms — anything else is
rejected so typos do not silently pass through to the runtime.

## Example
```rx
def main
  puts "path: c:\temp\new"
end
```

## Fix
Either escape the backslash itself, or use one of the supported
escapes. For Windows-style paths a raw string `r"..."` avoids the
issue entirely:

```rx
def main
  puts "path: c:\\temp\\new"
  puts r"path: c:\temp\new"
end
```
