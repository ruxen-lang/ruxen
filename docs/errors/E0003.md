# E0003: invalid escape sequence

## Why
A backslash inside a string or character literal was followed by a
character the lexer does not recognise as a valid escape. Ruxen
supports the usual `\n`, `\r`, `\t`, `\\`, `\"`, `\'`, `\0`, `\#`,
plus the unicode form (`\u{NNNN}`). Anything else is rejected so typos
do not silently pass through to the runtime.

## Example
```rx
def main
  puts "path: c:\data\files"
end
```

## Fix
Either escape the backslash itself, or use one of the supported
escapes. For Windows-style paths a single-quoted string avoids the
issue entirely: single quotes keep their content verbatim, with no
escape processing and no `#{}` interpolation:

```rx
def main
  puts "path: c:\\data\\files"
  puts 'path: c:\data\files'
end
```
