# E0007: malformed format spec

## Why
The lexer parsed a string interpolation `"#{expr:spec}"` whose `spec`
does not match the supported grammar:

```text
spec      := [fill align] [width] ['.' precision] ['?']
fill      := any non-`}` non-digit char (only meaningful with align)
align     := '<' | '>' | '^'
width     := <digit>+
precision := <digit>+
```

Two common shapes trip this:

1. A `.` not followed by precision digits (e.g. `"#{x:5.}"`).
2. Stray non-whitespace characters after the well-formed prefix
   (e.g. `"#{x:5xy}"`, `"#{x:?nope}"`, `"#{x:@@@}"`).

Whitespace inside the spec is tolerated; anything else is an error.

## Example
```rx
def main
  let pi = 3.14
  puts "pi=#{pi:5.}"     # `.` without precision digits
  puts "pi=#{pi:.2nope}" # stray junk after `.2`
end
```

## Fix
Drop the stray characters, or move them outside the interpolation:

```rx
def main
  let pi = 3.14
  puts "pi=#{pi:.2}"
  puts "pi=#{pi:.2}nope"
end
```
