# E0746: a generic instantiation nests too deeply

## Why

Ruxen compiles a generic body once per concrete type it is used with. A
body that uses itself with a larger type than it was given (`Nest[T]`
building a `Nest[Array[T]]`) asks for `Nest[Int]`, then
`Nest[Array[Int]]`, then `Nest[Array[Array[Int]]]`, with no end. The
compiler stops when a type argument nests deeper than 32 levels.

## Example

```rx
class Nest[T]
  v: T

  def init(@v: T)
  end

  def deeper -> Int
    # error[E0746]: the generic instantiation `Nest[Array[Array[...]]]`
    # nests deeper than 32 levels
    Nest.new([@v]).deeper
  end
end

puts(Nest.new(1).deeper)
```

## Fix

Keep the recursion on the same type, or stop it with a type that does not
grow: store the nested values in a field of a fixed type (`Array[T]`)
instead of a new instantiation per level.
