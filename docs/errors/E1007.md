# E1007: cannot borrow immutable variable as mutable

## Why
A mutable borrow promises the right to write through the reference,
so the underlying binding must be one that can change. Locals
introduced by `x = 1` and method parameters can. The variable of a
`for` loop, the parameters of a block or lambda, and a local introduced
with the [deprecated] `let` keyword (replaced by plain `x = 1`) cannot,
so `&var` of one of them is rejected.

## Example

Rejected with E1007 [implemented]:

```ruby
def bump(n: &var Int) -> nil
  n += 1
end

for i in 0..3
  bump(&var i)     # E1007: the loop variable is fixed
end
```

## Fix
Copy the value into a local of your own and borrow that.

Compiles and prints `1`, `2`, `3`, `4` [implemented]:

```ruby
def bump(n: &var Int) -> nil
  n += 1
end

for i in 0..3
  n = i
  bump(&var n)
  puts n
end
```
