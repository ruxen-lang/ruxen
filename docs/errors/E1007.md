# E1007: cannot borrow immutable variable as mutable

## Why
A mutable borrow promises the right to write through the reference.
The underlying binding must therefore be `let mut`. Borrowing a
plain `let` binding as `&mut` would let the callee mutate a value
the owner declared as fixed.

## Example
```rvn
def main
  let v = Vec.new()
  let m = &mut v       # E1007: v is not declared mut
  m.push(1)
end
```

## Fix
Declare the binding `mut`:

```rvn
def main
  let mut v = Vec.new()
  let m = &mut v
  m.push(1)
end
```
