# E1007: cannot borrow immutable variable as mutable

## Why
A mutable borrow promises the right to write through the reference.
The underlying binding must therefore be declared mutable with
`var`. Borrowing a `let` binding as `&mut` would let the callee
mutate a value the owner declared as fixed.

## Example
```rvn
def main
  let v: Array[Int] = Array.new
  let m = &mut v       # E1007: v is not declared with `var`
  m.push(1)
end
```

## Fix
Declare the binding with `var`:

```rvn
def main
  var v: Array[Int] = Array.new
  let m = &mut v
  m.push(1)
end
```
