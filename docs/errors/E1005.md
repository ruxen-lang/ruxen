# E1005: borrow outlives owner

## Why
A reference would still be live after the value it points to has
been dropped. Ruxen would let the program read freed memory if it
allowed this; the borrow checker rejects the program at compile
time instead.

## Example
```rx
def dangling -> &String
  let s = String.from("hi")
  &s             # E1005: s drops at end of fn, ref outlives it
end
```

## Fix
Return the value by ownership (move) or restructure the lifetimes
so the owner outlives the borrow:

```rx
def owned -> String
  String.from("hi")
end
```
