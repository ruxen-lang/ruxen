# E1010: returned reference outlives local value

## Why
The function returns a reference whose pointee is a local variable
of the function. Once the function returns, the local goes out of
scope and is dropped — the returned reference would dangle.

## Example
```rx
def first_word -> &String
  let s = String.from("hello world")
  &s           # E1010: &s outlives s
end
```

## Fix
Return the owned value, or accept the source by reference and
borrow from the caller's storage:

```rx
def first_word(src: &String) -> &String
  src
end
```
