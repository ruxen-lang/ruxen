# E0738: name in a `use` group not found

## Why

A grouped import `use pkg.Mod.{A, B}` binds each listed name. When the
module path cannot be walked and the compiler falls back to the
flat-merged top-level names, one of the listed names does not exist
there either, so it cannot be imported. This used to be skipped
without a word, leaving a later "undefined" error far from its cause.

## Example

```rx
class Box
end
class Holder
end
use pkg.Holder.Box.{Box, Nope}
# error: 'Box' not found in class 'Holder'
# error[E0738]: `Nope` not found for `use pkg.Holder.Box.{...}`
```

## Fix

Fix the module path so every hop exists, and import only names that
exist. A name that is already a top-level item needs no `use` at all.
