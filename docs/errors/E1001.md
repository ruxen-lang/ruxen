# E1001: value used after move

## Why
The borrow checker observed an attempt to use a value after its
ownership had been transferred (moved) elsewhere. Once a non-`Copy`
value is moved — into a function call, a new binding, or a struct
literal — the original binding is no longer valid; reading it would
read freed or aliased storage.

## Example
```rvn
def main
  let s = String.from("hello")
  let t = s        # ownership of s moves to t
  puts s           # E1001: s was moved into t
end
```

## Fix
Either clone the value before the move, borrow it instead, or
finish using it before the move:

```rvn
def main
  let s = String.from("hello")
  let t = s.clone
  puts s
  puts t
end
```
