# E0736: could not infer a function's parameter or return type

## Why

Type inference finished without settling a parameter type or the return
type of a function. This happens when nothing in the function body or at
any call site pins the type down.

## Example

```rx
def empty
  []
end
# error[E0736]: could not infer return type for function `empty`
```

## Fix

Annotate the parameter or return type, or call the function so the call
site fixes the type.

```rx
def empty -> Array[Int]
  []
end
```
