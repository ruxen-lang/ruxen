# E1127: `super` outside the `init` of a subclass

## Why
`super(...)` calls the parent class's `init` with the given arguments, on the
object being built. It only has a meaning inside the instance `init` of a class
that declares a parent (`class Child < Parent`).

The compiler used to accept `super` anywhere and compile it to nothing, so the
call was silently skipped. It is now an error.

## Example
```rx
class Point
  def init(x: Int)
    super(x)      # error[E1127]: `Point` has no parent class
  end
end

def helper
  super()         # error[E1127]: not inside an `init`
end
```

## Fix
- Give the class a parent (`class Point < Base`) if it should run the parent's
  `init`, or remove the `super` call.
- Call the parent's behaviour from other methods by name; `super` from an
  ordinary method is not supported yet.
