# E0610: auto-synth: field type does not satisfy the synthesized mixin's bound

## Why
A synthesized `Clone` walks every field (or enum variant payload) and
requires that each field type is itself `Clone`. Primitives, `String`,
the standard collections of `Clone` elements and user types whose
fields all qualify are `Clone`. An opaque C handle, such as a
`Mutex[Int]` (a fieldless class whose methods are C functions), is
not: copying its box would not copy the C object behind it.

E0610 fires on the type that says `include Clone` and names the field
that fails.

## Example

Rejected with E0610 [implemented]:

```ruby
class Guarded
  count: Int
  lock: Mutex[Int]       # a C handle: not Clone
  include Clone
end
```

## Fix
Drop `include Clone` (and do not call `clone`), or hold the shared
value through a handle that declares its own `clone`, such as
`SharedSync`.

Compiles [implemented]:

```ruby
class Guarded
  count: Int
  lock: SharedSync[Int]  # SharedSync#clone shares the handle
  include Clone
end
```
