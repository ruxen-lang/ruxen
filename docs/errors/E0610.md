# E0610: auto-synth: field type does not satisfy the synthesized mixin's bound

## Why
Auto-synthesis (§3.6) walks every field and requires that each
field type itself satisfies the mixin being synthesized. This
generic diagnostic fires at the use site when the synthesizer
reaches a field whose type fails the bound — for example,
synthesizing `Clone` for a struct whose field is an opaque
foreign type that is not `Clone`.

## Example
```rx
lib "ffi"
  type RawHandle
end

struct Wrapper
  inner: RawHandle             # not Clone
end

def main
  let a = Wrapper.new(/*...*/)
  let b = a.clone              # error[E0610]: RawHandle is not Clone
end
```

## Fix
Either accept that the type cannot satisfy that mixin (don't call
the mixin's methods), or change the field to a type that does
satisfy the bound — often by wrapping it in a `Clone`-able
container or providing a manual implementation in the type body:

```rx
struct Wrapper
  inner: Int                   # primitive: satisfies every auto mixin
end
```
