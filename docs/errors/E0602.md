# E0602: deriving Copy also requires Clone

## Why
`Copy` is a marker that strengthens `Clone`: every `Copy` type must
also be `Clone`. The compiler refuses to synthesize `Copy` in
isolation so that `value.clone()` always works on a `Copy` type.

## Example
```rvn
@[derive(Copy)]
struct Point
  x: Int
  y: Int
end
```

## Fix
Add `Clone` to the same `derive` list:

```rvn
@[derive(Copy, Clone)]
struct Point
  x: Int
  y: Int
end
```
