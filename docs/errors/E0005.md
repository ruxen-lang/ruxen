# E0005: unterminated character literal

## Why
A single-quote character literal opened with `'` but the closing
`'` never arrived on the same line. Character literals always hold
exactly one character (or one escape sequence) and must close
before the line ends.

## Example
```rx
def main
  let c = 'a
  puts "#{c}"
end
```

## Fix
Close the literal:

```rx
def main
  let c = 'a'
  puts "#{c}"
end
```
