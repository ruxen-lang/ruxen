# E0005: unterminated character literal

## Why
This code is no longer emitted. Ruxen has no `'a'` character literal:
single quotes delimit a string, as in Ruby, and a character literal is
written `?a` (or `?\n` for an escape).

A single quote that never closes on the same line is therefore an
unterminated string, reported as **E0002**.

## Example
```rx
def main
  let c = 'a          # error[E0002]: unterminated string literal
  puts "#{c}"
end
```

## Fix
Close the quote for a one-character `String`, or use `?a` for a `Char`:

```rx
def main
  let s = 'a'         # String
  let c = ?a          # Char
  puts "#{s} #{c}"
end
```
