# E1021: this value has no address to pass to a `&var` parameter

## Why
A `&var String` or `&var Int` (any scalar) parameter receives the
**address of the caller's storage**, so an assignment in the callee writes
the caller's variable, field or Array element directly
(`mir/refmut_abi.rs`). A variable, a field of an object and an Array
element each have such an address.

A Hash value (`h["a"]`), a field read through safe navigation
(`u&.name`) and a field of something that is not an object do not: the
value would be copied into a temporary, the callee would write the
temporary, and the write would be lost. That is rejected instead, whether
the argument is written `&var h["a"]` or passed to the `&var` parameter
directly.

## Example
```rx
def replace(s: &var String) -> nil
  s = "new"
end

h = {"a" => "old"}
replace(h["a"])   # E1021: a Hash value has no address
```

## Fix
Bind the value to a variable, pass the variable, and store it back:

```rx
h = {"a" => "old"}
s = h["a"].clone
replace(s)
h["a"] = s
puts h["a"]
```
