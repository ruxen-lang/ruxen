# E0733: bitwise complement requires an integer operand

## Why

The bitwise-complement operator `~` flips every bit of an integer, so its
operand must be an integer type. Applying it to a `Float`, `Bool`, `String`,
or any other type has no meaning.

## Example

```rx
let flipped = ~3.5
# error[E0733]: bitwise complement `~` requires an integer operand, found `Float`
```

## Fix

Apply `~` to an integer, or convert the value to an integer first.

```rx
let mask = ~0        # all bits set
let flipped = ~count # count: Int
```

For a logical negation of a `Bool`, use `!` or the keyword `not` instead.
