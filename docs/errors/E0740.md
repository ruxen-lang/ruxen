# E0740: no method with this name on the receiver's type

## Why

The receiver's type has a home class (a class, struct or enum, or a builtin
collection such as `Array`, `Set`, `Hash`, `Option` or `Result`), and that
class declares no method with the called name. The call used to type as an
unknown value and fail later, at link time.

## Example

```rx
def main
  let xs = Array.from(123)
  # error[E0740]: no method `from` on type `Array`
end
```

## Fix

Call a method the type declares, or build the value another way.

```rx
def main
  let xs = [123]
  puts xs.size
end
```
