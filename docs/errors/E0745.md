# E0745: a method's generic parameter shadows its type's generic parameter

## Why

A type parameter is known by its name. Inside `class Box[T]`, a method that
declares its own `T` (`def show[T](x: &T)`) would be indistinguishable from
the class's `T`, so its arguments and result would be typed with the
receiver's `T` instead of the method's.

## Example

```rx
class Box[T]
  v: T

  def init(@v: T)
  end

  def show[T](x: &T) -> nil
    # error[E0745]: generic parameter `T` shadows the enclosing type's `T`
    puts("#{x}")
  end
end
```

## Fix

Give the method's parameter its own name:

```rx
  def show[U](x: &U) -> nil
    puts("#{x}")
  end
```

A `where` predicate on the type's own parameter (`def get -> T where T:
Clone`) is not a new parameter and is allowed.
