# E0726: function reference needs arguments; call it or annotate a `Fn` type

Ruxen auto-calls a bare reference to a function or method when it is used in a
value position whose expected type is **not** a function type. For a function
that takes **zero** arguments this is seamless:

```ruxen
def args -> Array[String]
  # ...
end

def main
  let argv = args      # `args` auto-calls -> argv : Array[String]
  if argv.len < 2
    # ...
  end
end
```

This error fires when the bare reference names a function that **requires
arguments**, so it cannot be auto-called with zero arguments:

```ruxen
def add(a: Int, b: Int) -> Int
  a + b
end

def main
  let f = add          # ERROR E0726: `add` needs 2 arguments
end
```

## Fixes

**Call it** — supply the arguments:

```ruxen
let sum = add(1, 2)
```

**Reference it** — annotate a `Fn` type so the function is referenced without
being called (a `Fn`-typed context suppresses auto-call):

```ruxen
let f: Fn(Int, Int) -> Int = add
let sum = f(1, 2)
```

The same applies when passing a function to a higher-order function: if the
parameter is `Fn`-typed, the reference is passed as a value; otherwise it is
auto-called and its result is passed.
