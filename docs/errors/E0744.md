# E0744: a borrowed value is used where an owned value is required

## Why

An object owns its fields. Reading a field whose type is not Copy
(`String`, `Array[T]`, a class) gives a borrow `&T` of the value the object
still owns. A slot that owns a `T` (a by-value parameter, a `-> T` return,
a `let` or field typed `T`) would then own the same value too, and both
owners would free it. The same holds for any other borrow, such as a `&T`
parameter.

## Example

```rx
class User
  name: String
  def init(@name: String)
  end

  def name -> String
    @name
    # error[E0744]: expected an owned `String`, found the borrow `&String`
  end
end

def keep(s: String)
  puts(s)
end

def main
  let u = User.new("ada")
  keep(u.name)
  # error[E0744]: expected an owned `String`, found the borrow `&String`
end
```

## Fix

Clone the value to own a copy, or take the borrow where only reading is
needed.

```rx
class User
  name: String
  def init(@name: String)
  end

  def name -> &String
    @name
  end
end

def keep(s: String)
  puts(s)
end

def main
  let u = User.new("ada")
  puts(u.name)
  keep(u.name.clone)
end
```
