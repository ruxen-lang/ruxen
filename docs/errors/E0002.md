# E0002: unterminated string literal

## Why
A string literal opened with `"` (or a multi-line `"""`) reached the
end of the line or the end of the file before the matching closing
quote. Ruxen string literals must be closed on the same logical line
unless they use the multi-line `"""` form.

## Example
```rx
def main
  let greeting = "hello, world
  puts greeting
end
```

## Fix
Close the string with the matching quote, or use the multi-line form
when the value really spans lines:

```rx
def main
  let greeting = "hello, world"
  puts greeting
end
```
