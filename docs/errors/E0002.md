# E0002: unterminated string literal

## Why
A string literal opened with `"`, `'` (or a multi-line `"""`) reached
the end of the line or the end of the file before the matching closing
quote. Single-quoted strings are always single-line. Ruxen string literals must be closed on the same logical line
unless they use the multi-line `"""` form.

## Example

Rejected with E0002 [implemented]:

```ruby
greeting = "hello, world
puts greeting
```

## Fix
Close the string with the matching quote, or use the multi-line form
when the value really spans lines.

Compiles [implemented]:

```ruby
greeting = "hello, world"
puts greeting
```
