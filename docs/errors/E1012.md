# E1012: type does not satisfy Sync

## Why
Sharing a `&T` across threads requires `T: Sync` so that concurrent
reads are race-free. The compiler found a value whose type is
`!Sync` (typically a `Cell`, `RefCell`, or a type with interior
mutability that lacks synchronisation) being shared.

## Example
```rx
def main
  let cell = Cell.new(0)
  let r = &cell
  spawn move ||
    puts "#{r.get}"   # E1012: Cell[Int] is not Sync
  end
end
```

## Fix
Use a thread-safe interior-mutability primitive such as a `Mutex`
or an `AtomicI64` instead of `Cell` / `RefCell`:

```rx
def main
  let m = Mutex.new(0)
  let r = &m
  spawn move ||
    puts "#{r.lock.get}"
  end
end
```
