# E1012: type does not satisfy Sync

## Why
Sharing a value with several threads at once requires `Sync`, so that
concurrent reads are race-free. A parameter typed `any Sync` (or a
generic parameter bounded by `Sync`) states that requirement. A class
whose fields are all `Sync` is `Sync`; a raw pointer field is not, since
nothing guards what it points to.

## Example

Rejected with E1012 [implemented]:

```ruby
class Buffer
  ptr: *UInt8              # a raw pointer: not Sync
end

def share(v: any Sync)
  puts "shared"
end

def check(b: Buffer)
  share(b)                 # E1012: Buffer is not Sync
end
```

## Fix
Keep raw pointers behind a type that guards them (such as a `Mutex`),
or hold plain data.

Compiles and prints `shared` [implemented]; `def init` is [deprecated]: its replacement `initialize` is [planned](../../TODO.md#t-initialize):

```ruby
class Buffer
  len: Int

  def init(len: Int)
    @len = len
  end
end

def share(v: any Sync)
  puts "shared"
end

share(Buffer.new(4))
```
